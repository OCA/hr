This module lets you design and print business cards (vCards) for your
employees.

A company-wide card design is configured once (layout, font, background and
which fields to show) and can be printed for any employee as a two-sided PDF:
the front holds the branding (logo, company name) and the back the contact
details (name, job position, email, phone, website). Each card includes a QR
code with the employee's contact information, so it can be scanned straight
into a phone's address book.

The card adapts to the data available: only the selected fields that actually
have a value are shown.

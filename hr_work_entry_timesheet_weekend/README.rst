Native Odoo module hr_work_entry_contract, by default does not create
work entries on week-ends. This module extends the functionality of
hr_work_entry_timesheet from this same OCA repo to generate work entries
on week-ends in case you have timesheet registered on these days.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Usage
=====

To use this module, you need to:

-  Go to *Employees*

-  On an "Employee" form view, click on smart-button "Work entries"

-  On "Work entries" calendar view, click on "Regenerate work entries"
   and select dates

-  If you have timesheets on week-ends (meaning on days which are not
   listed in calendar resource attendance), you will get an
   hr_work_entry for that day, using "Not working day" type added by
   this module.

To use this module, you need to:

- Go to *Employees*

- On an "Employee" form view, click on smart-button "Work entries"

- On "Work entries" calendar view, click on "Regenerate work entries" and select dates

- If you have timesheets on week-ends (meaning on days which are not listed in calendar resource attendance), you will get an hr_work_entry for that day, using "Not working day" type added by this module.

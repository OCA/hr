To grant portal access to an employee:

1. Open the employee form (Employees app).
2. In the *Settings* tab, *User* section, click **Grant Portal Access**
   (visible only when no user is linked).
3. The employee's work contact receives the standard portal invitation
   email, and the created portal user is linked to the employee.

Once linked, the portal user's *Notification* preference defaults to
"In Odoo" and is visible on the user form. It can be changed back to
"By Emails" if needed.

On the Users list, the **Employee Portal** filter lists portal users that
are linked to an employee.

Use Cases / Context
===================

In France, when your employees have a contract with a specific number of
days worked per year, they need to validate every month the count of
days worked for the past month.

Function to validate already exists in native hr_work_entry module but
is not accessible on the interface.

Usage
=====

To use this module, you need to:

-  Go to *Employees*

-  On an "Employee" form view, click on smart-button "Work entries"

-  Switch to list view, select a number of entries and click on "Action"
   > "Validate work entries"

-  On form view, you can also click on "Action" > "Validate work
   entries"

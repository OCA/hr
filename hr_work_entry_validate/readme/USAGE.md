To use this module, you need to:

- Go to *Employees* / *My Work Entries* (new menu added by this module)

- On calendar view, in both "Monthly" and "Weekly" views you have a button "Validate period" that would validate all work entries from that period

- Alternatively, on list view, select a number of entries and click on "Action" > "Validate work entries" 

- On form view, you can also click on "Action" > "Validate work entries"

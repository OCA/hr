============================
HR Appraisal
============================

This module helps maintain the employee motivation process through periodic performance appraisals.

Managers can evaluate employee performance and enable employees to perform self-assessments.
Review forms can be customized according to organizational needs.

**Table of contents**

.. contents::
   :local:

Usage
=====
To use this module, you need to install the `hr_appraisal` module in your Odoo instance.
